# 🍹 Cocktail Finder

Découvrez des cocktails personnalisés en fonction de vos ingrédients ! Une application web immersive avec design rétro-futuriste inspiré des années 80.

🌐 **Lien de production** : (https://cocktail-finder-ajq5.vercel.app/)

## ✨ Fonctionnalités

- 🔍 Recherche de cocktails par nom ou ingrédient
- 🎨 Interface néon avec animations lumineuses
- 📱 Design responsive adapté à tous les écrans
- 🔒 Système d'authentification sécurisé (JWT)
- ❤️ Gestion des favoris utilisateur

## 🛠 Technologies

- **Frontend** : React, TypeScript, Vite
- **Backend** : Node.js, Express, MySQL
- **Styling** : CSS Modules, animations CSS
- **API** : TheCocktailDB
- **Déploiement** : Vercel
